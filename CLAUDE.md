# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

@AGENTS.md

## Claude Code

This repo is shared across coding agents via `AGENTS.md`, imported above. `AGENTS.md` is the
[cross-agent standard](https://agents.md) — Cursor, Codex, Gemini CLI, GitHub Copilot, Windsurf and
others read it natively. Claude Code is the outlier that reads `CLAUDE.md`, hence the import: edit
`AGENTS.md` for instructions that should apply everywhere, and put only Claude Code-specific notes
below this line.

### Local enforcement hooks (Claude Code only)

`.claude/settings.json` wires two `PreToolUse` hooks under `.claude/hooks/`. They run only inside
Claude Code sessions — other AGENTS.md-compatible agents don't read `.claude/` and aren't bound by
them:

- `block-no-verify.ts` — denies any Bash command containing `--no-verify`, `HUSKY=0`, `LEFTHOOK=0`,
  or `LEFTHOOK_EXCLUDE=`.
- `block-protected-edits.ts` — denies Edit/Write on generated or protected files (`public/map.js`,
  `public/turbo.js`, `public/output.css`, `output/licenses.json`, `.oxlintrc.json`, `.oxfmtrc.json`,
  `lefthook.yml`, `tsconfig.json`) and on any file whose first 200 characters contain
  "autogenerated". `settings.json`'s `permissions.deny` blocks the same paths at the permission
  layer as a second line of defense.

The mechanism-agnostic backstop is `lefthook.yml`: pre-commit runs `oxlint` + `oxfmt --check` on
staged files, pre-push runs `bun run typecheck` + `bun test`. It fires on `git commit`/`git push`
regardless of which agent produced the change, so it's what actually enforces the "Do not" rules in
`AGENTS.md` for every tool, Claude Code included.
